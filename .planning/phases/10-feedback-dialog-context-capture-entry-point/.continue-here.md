## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Ketcher WASM remount via HMR | Editing `App.tsx`'s JSX structure (adding/removing/reordering the direct children of `<div className="app">`) while the dev server is running makes React Fast Refresh tear down and re-subscribe the Ketcher `<Editor>` mid-flight. Console shows `couldnt find ketcher instance 2` and `createRoot(...): Target container is not a DOM element`. It is HMR-only — the production build is unaffected. | advisory | After any structural edit to `App.tsx`, do a full browser hard reload (Ctrl+Shift+R) rather than trusting HMR. Prefer adding UI inside leaf components (e.g. KetcherPanel's `.section-label`) over reshuffling App's direct children. |
