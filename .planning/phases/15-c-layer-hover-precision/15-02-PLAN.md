## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-05 | Tampering | ConnectionText renderSegment (LayerText.tsx) | accept | The CLayerToken array is derived from the verbatim InChI string (Ketcher WASM output, not user-typed text). Tokens carry only local integer atom indices and array positions — no execution paths, no eval, no dynamic code. An adversarially crafted InChI string can only produce a span with a wrong hover payload, which resolves to an empty highlight spec and no visible effect. |
| T-15-06 | Information Disclosure | None applicable | accept | subHoverProps closures carry only canonical atom indices (unsigned integers). No credentials, no PII, no user content beyond molecule topology. |
| T-15-07 | Denial of Service | collectBranchHyphens O(n) slice | accept | Branch size is bounded by c-layer length; deeply nested branches in real InChI strings are under 50 tokens. Slice + filter is O(n) with no recursion or unbounded allocation. |
| T-15-SC | Tampering | npm/pip/cargo installs | accept | Phase 15 introduces no new npm dependencies. No package install tasks; slopcheck not triggered. |

Note: LayerText.tsx changes are pure React rendering — no network, no auth, no persistence.
The trust boundary is a user hovering spans in their own browser; the worst adversarial
outcome is a wrong or empty canvas highlight (no security impact).
</threat_model>
