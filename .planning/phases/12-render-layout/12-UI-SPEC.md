## Spacing Scale

The project's existing strip uses a handoff-derived scale (multiples of 2, not strict 8-point). Phase 12 **mirrors `InchiSection` verbatim** (D-12) — do NOT introduce a new scale. Declared values in use for this strip:

| Token | Value | Usage |
|-------|-------|-------|
| section gap | 12px | `margin-top` on `.inchiKeySection` (matches `.inchiSection`) |
| chip padding | 2px 4px | Segment span padding (matches `.inchiLayer`) |
| box padding | 8px 14px | Display box padding; `padding-right: 40px` to clear copy button |
| copy btn inset | 10px | Copy button `right` offset (matches `.copyBtn`) |
| copied label inset | 36px | "Copied!" feedback `right` offset (matches `.copiedFeedback`) |
| empty hint padding | 4px 0 | Empty-state hint vertical padding |

Exceptions: This strip intentionally diverges from the global 8-point template to maintain pixel-parity with the existing InChI strip (handoff fidelity is a hard project constraint per CLAUDE.md). Reusing `InchiSection.module.css` values verbatim is the contract.

## Color

No new palette (D-01). Segment colors **reuse existing InChI layer tokens** to reinforce the conceptual link between InChIKey blocks and InChI layers. All values are oklch from `src/styles.css`.

| Role | Value (token) | Usage |
|------|---------------|-------|
| Dominant (60%) | `--bg-canvas` = `oklch(0.995 0.003 85)` | Display box background, page surface |
| Secondary (30%) | `--line` / `--line-soft` borders + `--ink-faint` `oklch(0.65 0.012 255)` | Box border, dimmed prefix, hyphens, hints |
| Accent (10%) | per-segment layer tokens (below) | The 5 colored segment spans only |
| Destructive | not used | No destructive actions in this phase |

### Segment → token mapping (D-01, 5 distinctly-colored spans per D-02)

| Segment kind (parser) | Token | Value | Rationale |
|-----------------------|-------|-------|-----------|
| `skeleton` (0–13) | `--c-conn` | `oklch(0.55 0.14 155)` (green) | Skeleton hash encodes connectivity → connectivity-layer green |
| `hash` (15–22) | `--c-stereo` | `oklch(0.58 0.15 112)` | Remaining-layers hash (stereo/isotope/proton) → stereo color |
| `flag` (23) | `--c-version` | `oklch(0.55 0.02 250)` | Standard/non-standard flag → version-layer color |
| `version` (24) | `--c-version` | `oklch(0.55 0.02 250)` | Version char `A` → version-layer color |
| `protonation` (26) | `--c-proton` | `oklch(0.55 0.14 325)` | Protonation char → proton-layer color |

Color application mirrors `swatchVar()` / `.inchiLayer` pattern: per-segment accent via inline `style` using `var(--c-<token>)`. The two hyphens (indices 14, 25) render in `--ink-faint`, dimmed and de-emphasized, NOT colored and NOT hoverable (mirrors `.inchiSlash`).

**Accent reserved for:** the 5 colored InChIKey segment spans (skeleton, hash, flag, version, protonation) and the active card's 3px left-border strip. Nothing else. Hyphens, prefix, and chrome stay neutral.

### Hover / dim treatment (D-12 — mirror `InchiSection` exactly)

- Active segment: background + color transition over **160ms ease** (mirrors `.inchiLayer` transition); active background applied via inline style from the segment's accent token.
- Dimmed siblings: **opacity 0.35** with 160ms transition (mirrors `.dim`).
- Chip padding/radius identical to `.inchiLayer` (2px 4px, radius 3px).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (copy button) | aria-label `Copy InChIKey` (icon-only button, mirrors InChI copy button); inline SVG, no visible text label |
| Copy confirmation | `Copied!` (resets after 3s; StrictMode-safe via `mountedRef`, D-11 / PLSH-04 parity) |
| Inline strip prefix | `InChIKey` — dimmed, ink-faint, no `=` (the key has no `=`); identifies the strip pre-hover (D-09) |
| Empty / placeholder state | `Draw a molecule above to see its InChIKey.` (parallels the InChI strip hint; shown whenever `parseInchiKey()` returns `[]` — i.e. key is not a valid 27-char format, D-10) |
| Error state | None. There is no error UI — an empty/invalid/unparseable key falls through to the placeholder above (PLSH-01 parity; no key, no error). |
| Destructive confirmation | Not applicable — no destructive actions in this phase. |

Card prose (per-segment explanation text) is **deferred to Phase 13**. Phase 12 only renders the card scaffolding the shared `Explanation` panel will fill. The 4 hover zones (D-07: `skeleton`, `hash`, `flag+version` combined, `protonation`) each surface one card slot.

## Interaction Contract (phase-specific, beyond the 6 standard dimensions)

| Behavior | Contract |
|----------|----------|
| Hover routing | Key-segment hover sets a NEW dedicated Zustand field (`keyHoverKind`, name at Claude's discretion) read ONLY by `Explanation`. It MUST NOT call `setHover`/`setSubHover` and MUST NOT reach `useKetcherHighlights` (Invariant #2 — the absence of canvas highlighting is the teaching point). |
| Hover zones | 4 zones, not 5: `[skeleton] - [hash][flag+version] - [protonation]`. Color spans stay 5 (D-08); only hover targeting groups flag+version into one combined card. |
| Panel precedence | `keyHoverKind` set → show key content; else `hoverIdx` set → InChI-layer content; else idle (D-04a). Only one strip hovered at a time; `onMouseLeave` clears each strip's own hover. |
| Verbatim render | Segment spans are produced by slicing the stored verbatim `inchiKey` at `parseInchiKey()` offsets. Never reconstruct/re-join (Invariant #1). Displayed key === copied key === raw stored `inchiKey`. |
| Empty state | Always render the box (do NOT unmount); toggle `data-empty="true"` → 0.45 opacity, soft border, `pointer-events: none` (mirrors `.inchiDisplay[data-empty="true"]`). |
| Canvas stability | `InchiKeySection` is a pure leaf sibling inserted between `<InchiSection />` and `<Explanation />` in `App.tsx` (D-05). Never touch `KetcherPanel` / module-level `structServiceProvider` (D-13 — canvas never remounts, WASM never re-inits). |
| Copy button | Duplicated inline in `InchiKeySection` (D-11 — not extracted to a shared hook); `mountedRef` reset-on-mount guards `setCopied(false)` against StrictMode double-mount; 3s reset; copies verbatim stored `inchiKey`. |
