## Trust Boundaries

This plan produces a pure, DOM-free, client-side string-formatting module plus its unit tests.
There is **no new attack surface**: `subTokenInfo` is a pure deterministic transform over
already-parsed numeric/symbol fields of a `SubHover` (built upstream from WASM-parsed InChI —
not user free-text), and it returns plain prose strings. No network, no persistence, no DOM, no
user-controlled input crosses any boundary in this plan. This is an honest minimal-surface
assessment, stated explicitly per the security contribution — not invented threats.

| Boundary | Description |
|----------|-------------|
| (none introduced) | `SubHover` fields are WASM-derived numerics/symbols, not user text; output is plain strings |
