<objective>
Close the two live-chemist-gate defects in the Phase-17 H-count card surface, both rooted in `atomPhrase()` in `src/lib/subTokenInfo.ts`:

- GAP-1 (blocker): a discrete H-count atom set is rendered as a false min–max range ("atoms 3–15" for the set {3,4,7,8,15}).
- GAP-2 (major): multi-component h-tokens print globally-offset canonical numbers ("atoms 19–23") that contradict the per-component numbers ("2-6") the chemist reads in the InChI string directly above the card.

Both fixes change `atomPhrase` in one coherent pass: enumerate the actual atoms (GAP-1) and subtract a display-only `fragmentOffset` (GAP-2). The canvas highlight keeps the global canonical values — `fragmentOffset` is carried as a new numeric `SubHover` field set in `LayerText` where the offset already lives, and is subtracted for display ONLY.

Purpose: A chemist hovering an h-layer token must read atom numbers that are (a) the exact atoms that bear hydrogens and (b) the same numbers printed in the InChI string. The Phase-18 wiring exposed two pre-existing Phase-17 rendering defects; this plan fixes the module where they live.

Output: Modified `subTokenInfo.ts`, `parseInchi.ts` (SubHover type), `LayerText.tsx` (3 construction sites); extended `subTokenInfo.test.ts`; new `LayerText.fragmentOffset.test.tsx`.
</objective>
