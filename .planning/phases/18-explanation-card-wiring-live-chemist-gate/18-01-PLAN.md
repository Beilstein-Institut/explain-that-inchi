## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WASM (Ketcher/InChI) → parser → store | InChI string + AuxInfo cross into JS; already parsed to offset-only numeric `SubHover` fields before this phase reads them. |
| store → Explanation.tsx render | The only boundary this phase adds code at: reads `subHover`/`pinned`/`atomElements` and renders text. No write-back. |

There is no client→server, network, persistence, or user-free-text boundary in scope. The molecule the InChI derives from is user-drawn, but it crosses through Ketcher's WASM and the existing offset-only parser — this phase never re-reads the raw string.
