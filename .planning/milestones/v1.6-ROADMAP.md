## Milestone Summary

**Key decisions:**
- c-layer atom card derives neighbours from `SubHover.incidentPairs` (the "other endpoint" of each incident pair); branch uses an explicit `branchPoint` field, identical on open and close parens.
- Per-component LOCAL display numbering (de-offset for display only); `SubHover` numbers stay GLOBAL — the auxMap highlight key (GAP-2 invariant), proven by `buildSubHoverSpecs` guards.
- **N* duplicated-fragment gap (UAT):** the card must collapse to one representative fragment in local numbering + state "in each of N identical components"; the highlight keeps lighting every copy (CLYR-05). Fixed via `SubHover.fragMult` (commit 2e881d9); same root cause that affected the h-layer card was fixed in the same change.
- c-layer card titles prefixed "Connection layer - Atom/Bond/Branch".
