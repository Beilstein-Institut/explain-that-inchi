# Requirements Archive: v1.5 — Sub-token-specific explanations

**Status:** ✅ SHIPPED 2026-06-29 (tag v1.5) · 10/10 requirements complete

**Goal:** The existing explanation card becomes sub-token-aware — hovering or pinning an
individual sub-token updates that same card to explain the specific piece, chemically
accurately. No new card or surface.

---

## v1.5 Requirements (all complete)

#### Card framework (sub-token tier)
- [x] **SUBEX-01**: Hovering a sub-token updates the *existing* explanation card with sub-token-specific content; reverts to the whole-layer explanation when only the layer is hovered.
- [x] **SUBEX-02**: A pinned sub-token (`pinned.sub`) shows its sub-token-specific card; precedence keyHoverKind → sub-token → layer → legend → idle.

#### Hydrogen sub-tokens
- [x] **SUBEX-03**: Hovering `H`/`H2`/`H3` (and ranges like `1-6H`) states the named atom(s) bear that many hydrogens — never a functional group ("methyl").
- [x] **SUBEX-04**: Hovering a mobile `(H,X,Y)` group explains a mobile/tautomeric hydrogen shared across the listed atoms — not a fixed bond.

#### Tetrahedral stereo (t-layer)
- [x] **SUBEX-05**: Hovering a t-layer stereocenter explains fixed 3-D handedness at an sp³ centre; `+`/`-` is a parity of canonical neighbour order.
- [x] **SUBEX-06**: The card states explicitly that `+`/`-` parity is **not** R/S, and notes the m/s layers qualify the enantiomer.

#### Molecular formula elements
- [x] **SUBEX-07**: Hovering an element updates the card with its name + that the count is that element's atom count, scoped to the hovered fragment, with a Hill-order note.
- [x] **SUBEX-08**: Element naming backed by a full periodic-table symbol→name table (case-exact; `Co` ≠ `CO`).

#### Correctness & non-regression
- [x] **SUBEX-09**: All copy derived from already-offset `SubHover` data — never reconstructs the InChI string; never remounts the canvas / re-inits WASM.
- [x] **SUBEX-10**: Copy produced by a pure, unit-tested module; real `getInchi()` fixtures only; "parity ≠ R/S" caveat pinned by test; passed a human chemical-accuracy gate.

### Out of Scope (this milestone)
- New explanation card / separate surface — enrich the existing card only.
- Element trivia (atomic number, group, mass) — encyclopaedia bloat.
- Asserting CIP R/S — InChI does not compute CIP.
- Functional groups from H-count — h-layer encodes a count, not connectivity.
- Sub-token cards for c-layer kinds — *deferred to v1.6 (delivered in Phase 19).*
