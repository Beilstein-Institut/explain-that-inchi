## Summary

The existing explanation card became sub-token-aware: hovering or pinning an individual
sub-token (element / H-count / mobile-H / tetrahedral stereo) updates that same card with
chemically-accurate, per-sub-token copy — no new card or surface. Backed by a full
periodic-table element-name table and a pure, unit-tested copy module, validated on real
molecules by a human chemist.

## Milestone Summary

**Key decisions:**
- Sub-token copy lives in a pure DOM-free `subTokenInfo.ts` module (verbatim-passthrough: consumes only already-offset `SubHover` fields; never re-joins `layer.text`).
- One new precedence branch inside `Explanation.tsx` (keyHoverKind → sub-token → layer → legend → idle); zero store changes; no canvas remount.
- GAP-1: H-count card enumerates the discrete atom set ({3,4,7,8,15}), never a min–max range.
- GAP-2: multi-component cards de-offset to per-component numbers for DISPLAY only; `SubHover.atoms` stay global (the auxMap highlight key).
- Chemical-accuracy gate (parity ≠ R/S; no functional-group naming from H-count; mobile-H is shared/tautomeric) enforced by tests + a live human-chemist review.

**Issues / tech debt:** None outstanding. Phase 17's SUBEX-10 chemist-prose gate was deliberately folded into Phase 18's live chemist gate (subTokenInfo only renders live in Phase 18); that gate passed.

**Stats:** 2 phases, 4 plans (incl. 1 gap-closure), 422 tests green at ship.
