per-sub-token copy that v1.5 deferred (`subTokenInfo` returned `null` for c-layer kinds).

## v1.6 Requirements (all complete)

- [x] **CONN-01**: Hovering/pinning a single c-layer atom number lists every canonical atom it is bonded to (full neighbour set, enumerated — no range, no truncation), or states it has no recorded bond.
- [x] **CONN-02**: Hovering/pinning a hyphen names the two canonical atoms it joins; a parenthesis describes the branch off its branch-point atom and lists the canonical bond pairs it encodes (open and close paren show the identical card).
- [x] **CONN-03**: In multi-component molecules the card's atom numbers match the per-component numbering printed in the string (reset after each `;`, `(component N)` marker) while `SubHover` payloads keep global canonicals so the highlight is unchanged — verified by a `buildSubHoverSpecs` guard. (Extended in-milestone to N* duplicated fragments via `SubHover.fragMult`.)
- [x] **CONN-04**: No connection card claims bond order, hydrogen count, or geometry; copy produced by the pure `subTokenInfo` module (no string reconstruction, no remount); real `getInchi()` fixtures (single-component + salt/co-crystal) + empty atom-list guard.
