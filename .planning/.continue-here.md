## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `pkill -f` self-match | `pkill -f "vite --port 5199"` matched the running shell's own command line and killed the whole chain mid-sequence (exit 144), silently skipping the `git commit` that followed it. Looked like a successful teardown; nothing was committed. | advisory | Resolve the PID and kill that instead: `PID=$(ss -lptn 'sport = :5199' \| grep -oP 'pid=\K[0-9]+' \| head -1); kill "$PID"`. Never `pkill -f` a pattern that appears in the command you are running. |
| SPA fallback masks 404 as a content result | Probing a deployed asset using a filename taken from the *local* `dist/` returned `HTTP 200` + `Content-Type: text/html` — nginx's `try_files` fallback serving index.html. With a `grep -i content-encoding` filter this was indistinguishable from "compression is off", and produced a confidently wrong conclusion. | advisory | Scrape the asset name from the *deployed* index.html (`curl -s <base>/ \| grep -oE 'assets/[^"]+\.js'`), and always assert `HTTP` status + `Content-Type` before concluding anything from a header probe. Note `nginx.conf` now 404s missing assets, which removes this trap for `.js/.css/.wasm` but not for other paths. |

<decisions_made>

- **Deleted § 3 (3) rather than rewriting it.** nginx sets COOP/COEP at the origin and the upstream proxy passes both through (verified by curl), so `coi-serviceworker.js` returns early at line 110 and never registers. The paragraph described an unreachable code path.
- **Precompress at build (`gzip -9` + `gzip_static`) over runtime gzip alone.** The largest chunk is 21 MB minified and content-hashed, so its bytes never change; runtime-gzipping it per cold request costs ~1–2s CPU for an identical result. Runtime `gzip on` remains as a fallback.
- **Excluded `application/wasm` from compression** to leave WASM streaming compilation undisturbed.
- **Repeated COOP/COEP in every new nginx location block.** `add_header` does not inherit into a block that declares its own; omitting them would silently break SharedArrayBuffer and therefore InChI computation.
- **Moved the title rule from `h2` border-top to `h1` border-bottom.** The `h2` rule is a section separator; it only landed under a title on Privacy, where an `h2` directly follows the `h1`. The `h1 + h2` selector suppresses the redundant separator there.
- **Footer Licenses link removed without losing attribution** — `TERMS_HTML` has a "Third-party components" section in-app and `THIRD-PARTY-NOTICES.md` is still at the repo root.
- **Did not add Playwright as a project dependency** for OG rasterizing; used the already-cached Playwright chromium via a throwaway script and documented the requirement in the `index.html` comment.
</decisions_made>
