## Critical Anti-Patterns

Rows 1–7 carry from the 260811 sessions. Rows 8–10 are from this one, and all
three are mistakes I actually made today, not hypotheticals.

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Assuming one deployment target | On-leave work was measured against nginx while GitHub Pages was still live. The workflow is deleted; the `gh-pages` branch is not. | blocking | Enumerate every live deploy target before claiming header- or endpoint-dependent behaviour works. |
| SIGTERM to headless Chrome does not fire `pagehide` | First on-leave measurement showed nothing wiped; the wipe never ran. | advisory | Trigger a real navigation and confirm the beacon in the SERVER log. |
| LevelDB tombstones read as live data | `strings` showed `ketcher-opts` after a successful wipe. | advisory | Read committed values via a same-origin probe or CDP, never from disk bytes. |
| Cache directory size is not an eviction signal | 18 MB vs 9.3 MB looked like a partial purge. | advisory | Count entries for the origin against an IDENTICAL-content baseline. |
| Concluding "config is broken" from a missing tool | Three settings files reported BROKEN during /doctor; `jq` is not installed. | advisory | Verify the tool exists before believing its failure. |
| `# syntax=docker/dockerfile:1` needs the network | `docker build` failed on a DNS timeout before parsing line 1. | advisory | Nothing here needs the directive. |
| Auditing docs against the previous session's notes | A handoff records what was decided, not what shipped. | advisory | Audit text against the source tree and build output. |
| **Static evidence cannot exonerate your change** | A browser mount failure was reported and attributed to my change. I answered twice with a grep of my diff ("no react/mount lines added") and a curl of the module graph ("server serves one react-dom") — neither can distinguish innocent code from code that breaks at runtime. Cost two rounds and the user's patience. | blocking | To claim "not mine", **bisect or write a test that fails without the fix**. A diff that looks innocent is a hypothesis, not evidence. |
| **A guard is worthless until you try to break it** | The first tour-anchor test scanned all sources *including* `HelpTour.tsx`, whose `STEPS` array contains the very selector strings being searched for. Every assertion matched its own declaration. Renaming the anchor left all 27 tests green. | blocking | After writing a guard, **delete the thing it guards and watch it fail.** Applied to both new tests today; the label test was confirmed failing against the old `<p>` markup first. |
| **A hard-coded box constant is a lie with a timer** | `CALLOUT_HEIGHT = 180` described a card that renders ~214px. Placement trusted it, anchored by `bottom`, and put the card off-screen — while every existing test passed, because jsdom has no layout. I fixed the *width* version of this bug an hour earlier while looking straight at the height constant on the next line. | blocking | Measure the box. When a layout constant and a rendered element disagree, the element wins. Fixing one instance means grepping for its siblings. |

The accessibility record is now an understatement and someone should decide what
to do about it. PRODUCT.md says keyboard and colour-independent equivalents are
"undecided rather than deliberately excluded" — the user confirmed that wording
this session. The code disagrees: `lib/keyboardProps.ts` gives layer chunks

all four hover components pair `onMouseEnter` with `onFocus`; there are 23
`focus-visible` rules; and every layer's prefix character carries its identity
independently of colour. This was reported in the audit and deliberately not
"fixed", because repairing drift as a side effect of a design task is forbidden.
It wants a decision, not an edit.
