# Quick Task 260811-f1u — Close two legal-content gaps

## Why

A review of the three legal pages against the code (post-`7866ad1` / `df4121d`) found
two places where the documents no longer match what the app ships and does:

1. **`public/coi-serviceworker.js` is undeclared.** It is vendored (not an npm
   dependency, so `package-lock.json` does not cover it), shipped in `dist/`, and
   loaded by `index.html:41`. Neither the `TERMS_HTML` bundled-component list nor
   `THIRD-PARTY-NOTICES.md` names it. MIT compliance itself already holds — the
   file carries its own `/*! coi-serviceworker v0.1.7 — Guido Zuidhof … MIT */`
   header in every distributed copy — so this is an incomplete attribution list,
   not a licence breach.
2. **Privacy § 3 (4) understates the purge's blast radius.** It says the site asks
   the browser to clear "its cached files and its stored data for this website".
   `Clear-Site-Data` is scoped by the spec to the **origin**, so leaving clears
   cache and storage for everything on `cheminfo.beilstein.org`. The nginx config
   and `src/lib/leaveWipe.ts:84-87` document this; the policy does not.

Out of scope (operator actions, not text): redeploying so § 3 (2)/(4) become true
in production, and confirming host log rotation ≤ 14 days for § 2 (2).

## Tasks

### Task 1 — Declare coi-serviceworker in both attribution surfaces

- **files:** `THIRD-PARTY-NOTICES.md`, `src/data/legalContent.ts`
- **action:** Add a `## coi-serviceworker — MIT License` section to the notices
  file (version 0.1.7, © Guido Zuidhof and contributors, vendored in `public/`,
