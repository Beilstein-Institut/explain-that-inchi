# Quick Task 260902-i2t: Grey out the legend while the canvas is empty

Follows 260902-hzh (legend inert on empty canvas). User asked whether the bottom two cards should
grey out like the InChI/InChIKey boxes; agreed: legend yes, explanation card no (it carries the only
"draw a molecule" instruction).

## Change
- `Legend.tsx`: `isEmpty = layers.length === 0`; card gets `data-empty="true"` while empty (same
  attribute the string boxes use); rows get `tabIndex={isEmpty ? -1 : 0}` so a focus that would do
  nothing is not offered.
- `Explanation.module.css` (where `.legendCard` lives): `.legendCard[data-empty="true"]` with the
  same three declarations as `.inchiDisplay[data-empty="true"]` — opacity 0.45, `--line-soft`
  border, `pointer-events: none`.
- Explanation card untouched.

## Tests
- `Legend.touch.test.tsx`: empty → `data-empty="true"` and all 11 rows `tabindex="-1"`; benzene →
  no attribute, 11 rows `tabindex="0"`.
- `legendPresence.test.ts`: CSS probe — the legend's empty rule shares opacity, border-color and
  pointer-events with the InChI box's, so the two cannot drift apart.

## Verify
`npx tsc -b`, lint, `npm test -- --run` green. Browser: empty canvas → legend visibly dimmed, ring
swatches still discernible; load a preset → legend comes back.
